시행일: 2026년 11월 5일

스탯로그(statlog.kr, 이하 "이 사이트"와 이 사이트를 감싼 안드로이드 앱)는 이용자의 개인정보를 수집하지 않는 것을 원칙으로 운영합니다. 아래는 그 내용을 사실대로 적은 것입니다.

1. 수집하는 개인정보

없습니다. 회원가입, 로그인, 댓글, 결제, 설문 기능이 없으며 이름·전화번호·주소·이메일·위치·연락처·사진·기기 식별자를 받지 않습니다.

2. 사용하지 않는 것

  • 방문자 추적·분석 도구(구글 애널리틱스 등)와 광고 추적 스크립트를 쓰지 않습니다.
  • 외부 광고 네트워크를 쓰지 않습니다. 사이트가 외부 스크립트를 불러오지 못하도록 기술적으로 막혀 있습니다.
  • 쿠키를 사용하지 않습니다.

3. 이용자 기기에 저장되는 정보

"내 팀" 즐겨찾기를 쓰면 선택한 팀 이름이 이용자 기기의 브라우저 저장소(localStorage)에만 저장됩니다. 서버로 전송되지 않으며 운영자가 볼 수 없습니다. 앱처럼 빠르게 열리도록 화면 파일 일부가 기기에 임시 저장(캐시)될 수 있습니다. 브라우저·앱 설정에서 사이트 데이터를 지우면 삭제됩니다.

4. 접속 기록

이 사이트는 GitHub Pages(GitHub, Inc.)로 제공됩니다. 접속할 때 호스팅 업체가 보안·운영 목적으로 IP 주소 등 일반적인 접속 기록을 처리할 수 있으며, 운영자는 이 기록에 접근하지 않고 별도로 보관하지 않습니다. 자세한 내용은 GitHub 개인정보 처리방침을 참고하세요.

5. 외부 링크

광고 배너나 안내 링크를 누르면 해당 외부 사이트로 이동하며, 그곳의 개인정보 처리는 그 사이트의 방침을 따릅니다. 광고는 운영자가 직접 심사한 것만 싣고 자세한 기준은 안내·광고정책에 있습니다.

6. 어린이·청소년

이 사이트는 만 19세 미만을 대상으로 하지 않으며, 만 14세 미만 아동의 개인정보를 수집하지 않습니다.

7. 방침 변경
