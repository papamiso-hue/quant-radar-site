앱처럼 쓰기 · 홈 화면에 추가

이렇게 하면 좋아요

  • 폰 홈 화면에 스탯로그 아이콘이 생겨서, 아이콘만 누르면 바로 열려요. (주소 입력 필요 없음)
  • 앱처럼 주소창 없이 꽉 찬 화면으로 보여요. 설치비·가입비는 없고, 스토어에서 받는 게 아니에요.
  • 인터넷이 끊겨도 마지막으로 본 화면이 열려요.
  • 언제든 아이콘을 지우면(길게 눌러 삭제) 깔끔하게 없어집니다.

✔ 이미 앱처럼 쓰고 계세요!

✔ 추가됐어요!

🍎 아이폰 · 아이패드 (사파리)

반드시 사파리(Safari)로 statlog.kr을 연 상태에서 시작하세요. 카카오톡·네이버 앱 안에서 열면 메뉴가 안 보일 수 있어요. 그럴 땐 링크를 길게 눌러 "사파리로 열기"를 고르세요.

🤖 안드로이드 (크롬)

크롬(Chrome)으로 statlog.kr을 연 상태에서 시작하세요. 삼성 인터넷은 오른쪽 아래 ≡ → 「+ 현재 페이지 추가」 → 「홈 화면」 순서예요.

💻 컴퓨터 (크롬 · 엣지)

주소창 오른쪽 끝에 설치 아이콘(모니터에 아래 화살표)이 보이면 누르면 돼요. 아이콘이 안 보이면 오른쪽 위 점 세 개 메뉴에서 「앱 설치」 또는 「스탯로그 설치」를 고르세요.

자주 묻는 질문

메뉴에 「홈 화면에 추가」가 안 보여요

아이폰은 사파리에서만 확실히 보여요. 안드로이드는 크롬 최신 버전을 쓰세요. 사이트를 한 번 새로고침한 뒤 다시 해 보세요.

돈이 드나요? 개인정보를 가져가나요?

아니요. 스탯로그는 가입·로그인·방문자 추적 도구가 없고, 홈 화면 추가는 바로가기(+저장본)를 만드는 것뿐이에요.

어떻게 지우나요?

아이폰: 아이콘 길게 누르기 → 「앱 제거」. 안드로이드: 아이콘 길게 누르기 → 「삭제」 또는 「설치 제거」. 컴퓨터: 앱 창 오른쪽 위 ⋮ → 「제거」.

더 편하게 보는 방법

  • ★ 내 팀: 경기 카드에서 팀 이름 옆 ☆를 누르면, 「★ 내 팀」 탭에서 그 팀 경기만 모아 볼 수 있어요. (이 기기에만 저장돼요)
  • 이 경기만 보기 · 공유: 경기 카드 오른쪽 위 버튼으로 한 경기 주소를 친구에게 보낼 수 있어요.

매주 금요일 저녁, "이번 주말 경기 확률 요약"을 텔레그램 채널로 보낼 예정입니다. (채널 준비 중)
